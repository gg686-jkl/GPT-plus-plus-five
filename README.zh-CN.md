# Plus Double Five

[English](README.md)

只需在手机上输入一句简短的提示词，就能在准备进行大量工作之前，提前开启 ChatGPT Work/Codex 的五小时用量窗口。

## 使用方法

1. 在手机上打开 ChatGPT，进入 **Work**。
2. 选择 **GPT-5.6 Luna**，并将推理强度设为 **Light**。
3. 粘贴下面的提示词：

   > At 4:00 AM tomorrow, say “Hi” to me once.

4. 确认创建这个仅执行一次的定时任务。

就这么简单。根据实际测试，定时任务会自动使用你在 Work 中选择的 Luna/Light 配置。

你可以把 `4:00 AM` 改成需要的时间。例如，如果你准备在早上 8:00 开始集中工作，可以让这个任务在凌晨 4:00 运行。这样第一个五小时窗口会提前开始，下一个窗口可能会在早上 9:00 左右开启。

## 请注意

这个方法不会增加用量，也不会绕过限制。这个小型定时任务本身会消耗一部分 ChatGPT Work/Codex 的共享用量，而且每周限制仍然有效。OpenAI 也可能随时调整相关机制。使用前请在 **Settings → Usage** 中确认你账户的实际重置时间。
