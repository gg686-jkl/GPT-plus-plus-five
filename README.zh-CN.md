# GPT-plus-plus-five

[English](README.md)

**当你知道自己即将进行一次长时间、高强度的工作时，把两个 ChatGPT Work/Codex 五小时用量窗口安排在相邻的时间段内。**

思路非常简单：用一个极小的定时任务提前开启第一个五小时窗口。在这个窗口即将结束时开始真正的工作，然后在下一个五小时窗口开启后继续工作。

## 示例：早上 8:00 开始大量工作

```text
凌晨 4:00   定时的“Hi”运行 → 第一个五小时窗口开始
早上 8:00   开始真正的工作
早上 9:00   第一个窗口结束 → 新的五小时窗口可以开始
下午 2:00   第二个五小时窗口结束
```

这样，一次集中的工作过程就能使用**前后两个五小时窗口**的用量，而不必在最需要额度时再等待五小时重置。

## 完整设置方法

1. 在手机上打开 ChatGPT，进入 **Work**。
2. 选择 **GPT-5.6 Luna**，并将推理强度设为 **Light**。
3. 粘贴：

   > At 4:00 AM tomorrow, say “Hi” to me once.

4. 确认创建这个仅执行一次的定时任务。

就这么简单。根据实际测试，定时任务会自动使用你在 Work 中选择的 Luna/Light 配置。你可以按照自己的计划修改 `4:00 AM`。

## 请注意

这个时间安排技巧不会创造额外用量，也不会绕过限制；它只是把两个正常的用量窗口安排到你需要的时间附近。定时发送“Hi”本身会消耗少量 ChatGPT Work/Codex 共享用量，每周限制仍然有效，而且 OpenAI 可能调整相关机制。使用前请在 **Settings → Usage** 中确认账户的实际重置时间。
